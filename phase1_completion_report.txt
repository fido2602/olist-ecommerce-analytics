## 2. Data Import and Preparation

The source CSV was imported into `olist_products_stage` using MySQL `LOAD DATA LOCAL INFILE`.

The initial import and subsequent validation revealed missing values in several descriptive attributes. A backup table and a test staging table were created during troubleshooting. Alternative import configurations were evaluated to investigate how blank CSV fields were being represented in MySQL.

A rebuild table was subsequently created and populated from the corrected test table. The staging table was replaced through a table-renaming operation, with the former staging table retained under an old-table name as part of the historical workflow.

- `product_name_length`

The original staging schema used the source-style spellings `product_name_lenght` and `product_description_lenght`. These spelling differences should be accounted for when reviewing historical SQL statements.

Missing category values should also be considered explicitly in category-level reporting so that products with unknown categories are not silently excluded.

## 7. Relationship to Order Items

The Products dataset was checked against `olist_order_items_dataset`, which contains product IDs associated with individual order items.

The recorded validation found that all 32,951 product IDs in the Products table matched product IDs in the Order Items dataset. No order-item product IDs were found without a matching product record, and no Products records were found without a corresponding order-item reference.

This relationship supports joining the tables through `product_id`.

The relationship is not one-to-one: a product can appear in many order-item records because the same product may be purchased across multiple orders or included in multiple order items.

Analytical queries should distinguish between:

- **Product count:** the number of distinct products.
- **Order-item count:** the number of individual product lines purchased.
- **Units sold:** the sum of item quantities, where the relevant quantity field is available.

These measures answer different business questions and should not be substituted for one another.
