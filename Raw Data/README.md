# Raw Data

This project uses the **Brazilian E-Commerce Public Dataset by Olist**, containing CSV tables for orders, customers, products, sellers, payments,
reviews, and related marketplace data.

## Original Dataset

**Kaggle dataset:**  
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

If the link does not open when clicked, copy and paste the full URL into your browser.

## Local Setup

1. Download the dataset from Kaggle.
2. Extract the CSV files.
3. Place the nine source CSV files in this folder, keeping their original filenames.
4. Follow the SQL scripts in the repository to prepare and analyze the data.

## Data Organization

Raw source files are kept separate from SQL analysis, Excel workbooks, Power BI reports, and project documentation.
