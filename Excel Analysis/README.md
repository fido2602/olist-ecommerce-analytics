# Excel Analysis

This folder contains Excel-based analyses completed for the Olist Brazilian E-Commerce project.

The workbooks examine business performance across key areas, including:

- Delivery performance and order trends
- Product-category performance
- Customer behavior and retention
- Customer reviews and satisfaction
- Payment behavior
- Seller performance

Each workbook supports the broader project by organizing data, analyzing business metrics, and identifying findings that can inform operational and commercial decisions.

**Tools:** Microsoft Excel

**Related analyses:** SQL data preparation and analysis, and Power BI dashboards.
