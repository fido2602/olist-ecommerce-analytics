# SQL Analysis

This folder contains SQL scripts used to prepare, validate, model, and analyze the Olist e-commerce dataset.

The scripts cover:

- **Data Import and Cleaning:** Preparing source data for analysis.
- **Data Modeling:** Establishing table relationships and analytical structures.
- **Business Analysis:** Investigating sales, customer behavior, delivery performance, product categories, and reviews.
- **Data Quality:** Validating records, checking consistency, and documenting data issues.

**Tools:** MySQL and MySQL Workbench

The SQL analysis provides the foundation for the Excel analyses and Power BI dashboards in this project.
